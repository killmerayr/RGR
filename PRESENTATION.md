## 📚 ПОДРОБНЫЙ РАССКАЗ О КОДЕ

### ЧАСТЬ 1: ОБЩАЯ АРХИТЕКТУРА

#### Структура проекта
```
main/main.cpp ─────► Главная программа (dlopen/dlsym)
    ↓
    ├── lib/libCodewordCipher.so
    ├── lib/libTabletCipher.so
    └── lib/libTarabarCipher.so
```

**Почему динамическая загрузка?**
- **Гибкость**: можно менять алгоритмы без перекомпиляции основного кода
- **Модульность**: каждый шифр — независимый компонент
- **Масштабируемость**: легко добавить новые алгоритмы

#### Как это работает в main.cpp
```cpp
void* handler = dlopen("./lib/libCodewordCipher.so", RTLD_LAZY);
CryptoFunc encrypt = (CryptoFunc) dlsym(handler, "codewordEncrypt");
encrypt(inputPath, outputPath);  // вызываем функцию из библиотеки
dlclose(handler);
```

**RTLD_LAZY** — библиотека загружается ленивым методом (функции ищутся при вызове)

### ЧАСТЬ 2: АЛГОРИТМ 1 — КОДОВОЕ СЛОВО (ВИЖЕНЕР)

**Историческая справка**: Шифр Виженера — это полиалфавитный шифр подстановки, созданный в XVI веке.

#### Принцип работы

1. **Создание таблицы подстановки**:
   - Берётся кодовое слово (пример: "HELLO")
   - Строится таблица, где первая строка — это уникальные буквы кодового слова
   - Остальная таблица заполняется оставшимися буквами алфавита

   Пример для англ. букв:
   ```
   Исходный алфавит:  a b c d e f g h i j k l m n o p q r s t u v w x y z
   Кодовое слово:     h e l l o ...
   Результат:        h e l o a b c ... (h первый, потом e, потом уникальные)
   ```

2. **Шифрование**:
   ```
   буква 'a' (позиция 0) → таблица[0] → 'h'
   буква 'b' (позиция 1) → таблица[1] → 'e'
   буква 'c' (позиция 2) → таблица[2] → 'l'
   ```

3. **Регистр сохраняется**:
   - 'A' шифруется как 'H' (большое)
   - Все не-буквенные символы остаются без изменений

#### Поддержка русского языка (UTF-8)
Программа работает с **кодовыми точками Unicode**:
```cpp
uint32_t utf8_to_cp(string, pos, bytes)  // преобразует UTF-8 в кодовую точку
string cp_to_utf8(uint32_t cp)          // преобразует кодовую точку в UTF-8
```

Русские буквы: А-Я, а-я, ё
- Маппинг: ё (0x0451) имеет особую обработку (после 'е')

#### Защита паролем
```cpp
string password = Password();          // запрашиваем пароль
string passHash = hashPassword(password);  // хешируем его
savePasswordToFile(outputPath, passHash);  // сохраняем в файл .codeword
```

При дешифровании:
```cpp
if (!checkPasswordFromFile(inputPath, password)) {
    // отклоняем ошибку пароля
    return;
}
```

### ЧАСТЬ 3: АЛГОРИТМ 2 — ТАБЛИЧНАЯ ПЕРЕСТАНОВКА

**Тип**: Алгоритм перестановки (транспозиции) — один из самых древних методов шифрования.

#### Принцип работы

1. **Блокировка текста**:
   - Текст разбивается на блоки размером 8×8 = 64 байта
   - Каждый блок — это матрица 8×8

2. **Две перестановки** (поэтому — *двойная* табличная перестановка):

   **Шаг 1: Перестановка по столбцам**
   ```
   Исходный блок:        Применяется ключ столбцов:
   A B C D E F G H       3 1 4 1 5 9 2 6
   I J K L M N O P
   
   Результат: строки переставляются по позициям из ключа
   ```

   **Шаг 2: Перестановка по строкам**
   ```
   Применяется ключ строк, который переставляет строки целиком
   ```

3. **Генерация ключей**:
   ```cpp
   vector<int> generateRandomKey(size_t size) {
       vector<int> key = [0, 1, 2, 3, 4, 5, 6, 7];
       shuffle(key);  // перемешиваем
       return key;
   }
   ```

4. **Сохранение ключей**:
   - Ключи сохраняются в файл `.keys` вместе с хешем пароля
   - При дешифровании нужно ввести оба ключа вручную (или прочитать из файла)

#### Дешифрование
Функция `Unshuffle` применяет обратные перестановки в обратном порядке:
```cpp
// Обратная перестановка по строкам
// Обратная перестановка по столбцам
```

### ЧАСТЬ 4: АЛГОРИТМ 3 — ТАРАБАРСКАЯ ГРАМОТА

**Историческая справка**: Это русский криптографический метод, где буквы зеркалируются в алфавите.

#### Принцип работы

Таблица замен строится путём создания пар символов:

**Для русского языка:**
- Гласные: а↔я, е↔ю, ё↔э, и↔ы, о↔у
- Согласные: б↔щ, в↔ш, г↔ч, д↔ц, ж↔х, з↔ф, к↔т, л↔с, м↔р, н↔п

**Для английского языка:**
- Гласные: a↔u, e↔o, i↔i, o↔e, u↔a
- Согласные: b↔n, c↔p, d↔q, f↔r, g↔s, h↔t, j↔v, k↔w, l↔x, m↔z

#### Реверсивность
Таблица **обратима** — если применить шифрование дважды, получится исходный текст:
```
A → A' → A (если A' → A в таблице)
```

Поэтому для шифрования и дешифрования используются почти одинаковые функции.

#### Регистр
Все операции чувствительны к регистру:
```cpp
// Если буква большая, результат тоже будет большим
if (isUpper) {
    return mapped - 0x20;  // преобразуем в большой регистр
}
```

### ЧАСТЬ 5: ПОТОК ВЫПОЛНЕНИЯ ПРОГРАММЫ

#### Главный цикл (main.cpp)
```
1. Показать меню выбора алгоритма
   ↓
2. Пользователь выбирает: Виженер / Табличная / Тарабарская
   ↓
3. Показать меню: Шифровать / Дешифровать
   ↓
4. Запросить путь к входному файлу
   ↓
5. Создать имя выходного файла (добавить суффикс _encrypted или _decrypted)
   ↓
6. Вызвать правильную функцию через dlopen/dlsym
   ↓
7. Повторить (бесконечный цикл до выхода)
```

#### Типичный сценарий шифрования
```cpp
// 1. dlopen загружает библиотеку
void* handler = dlopen("./lib/libCodewordCipher.so", RTLD_LAZY);

// 2. dlsym получает функцию из библиотеки
CryptoFunc encrypt = (CryptoFunc) dlsym(handler, "codewordEncrypt");

// 3. Функция вызывается
encrypt(inputPath, outputPath);

// 4. Внутри функции:
//    - Запрашивается кодовое слово
//    - Запрашивается пароль
//    - Читается входной файл
//    - Применяется алгоритм шифрования
//    - Записывается выходной файл
//    - Сохраняется пароль в метаданные

// 5. dlclose закрывает библиотеку
dlclose(handler);
```

### ЧАСТЬ 6: РАБОТА С ФАЙЛАМИ И УТИЛИТЫ

Файлы в проекте используются утилиты из `main/utils.h`:

```cpp
vector<unsigned char> readFileBinary(const string& path);
void writeFileBinary(const string& path, const vector<unsigned char>& data);
string hashPassword(const string& password);
bool verifyPassword(const string& input, const string& hash);
string Password();  // запрашивает пароль с подтверждением
```

#### Бинарная работа с файлами
- Все файлы читаются/пишутся как **бинарные данные** (вектор `unsigned char`)
- Это позволяет работать с любыми файлами, не только текстовыми

#### Хеширование паролей
- Пароли не сохраняются в открытом виде
- Сохраняется хеш пароля
- При проверке: хешируем введённый пароль и сравниваем

### ЧАСТЬ 7: МЕТАДАННЫЕ (ФАЙЛЫ С РАСШИРЕНИЯМИ)

Каждый алгоритм создаёт файл с метаданными:

| Алгоритм | Файл метаданных | Содержимое |
|----------|-----------------|-----------|
| Виженер | `.codeword` | хеш пароля |
| Табличная | `.keys` | хеш пароля + ключи перестановок |
| Тарабарская | `.tarabar` | хеш пароля |

Пример:
```
original_file.txt
original_file.txt_encrypted      ← зашифрованный файл
original_file.txt_encrypted.keys ← метаданные (ключи + пароль)
```
